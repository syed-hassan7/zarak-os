ZARAK_OS is an immersive portfolio OS web app built with React, TypeScript, Vite, and Three.js.

It uses a custom OS shell with window management, dock, menu bar, Spotlight, Mission Control, app windows, and a 3D workstation environment to present Zarak’s background, CV, LinkedIn snapshot, and projects as a product-like experience rather than a static website.
